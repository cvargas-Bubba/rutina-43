# Rutina 43+

Programa de 12 semanas de fuerza y resistencia con mancuernas, pensado para retomar
el ejercicio después de los 40: sesión del día con figuras animadas de cada ejercicio,
temporizador de descanso y registro de progreso.

Los registros se guardan solo en el dispositivo (localStorage). Desde Ajustes se puede
descargar y restaurar un respaldo `.json`.

Este sitio se genera con `02_trabajo/construir-sitio.ps1` a partir de `rutina-43.html`;
no editar `index.html` a mano.
